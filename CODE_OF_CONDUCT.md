# Code of conduct

OnlyBackup adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct for issues, pull requests, discussions and any other
project space.

In short: be respectful and constructive, assume good faith, focus criticism on
the work rather than the person, and do not harass anyone. Maintainers may edit
or remove contributions and restrict participation when this code is not
followed.

Report unacceptable behavior privately to the maintainers through the contact
details on the [repository owner's GitHub profile](https://github.com/meiome).
Do not use public issues for reports. Reports are handled confidentially.

Security vulnerabilities are not conduct reports; follow [SECURITY.md](SECURITY.md).
