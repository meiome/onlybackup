# Security reporting

Report suspected vulnerabilities privately through
[GitHub vulnerability reporting](https://github.com/meiome/onlybackup/security/advisories/new).
You can also open the repository's Security tab, select Advisories, and choose
Report a vulnerability. Read [the security model and reporting guidance](docs/SECURITY.md#reporting-a-vulnerability)
for the project's boundaries and useful report details.

Do not include credentials, private keys, production data, or exploit details in
public issues. Include the affected version or commit, impact, and a minimal
reproduction using synthetic data in the private report.
